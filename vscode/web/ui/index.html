Was ist Syntax Bot?

Syntax Bot ist ein Coding-Assistent für Menschen mit Lese-Rechtschreib-Schwäche (LRS). Er verbessert Rechtschreibung und Syntax in deinem Code — ohne die Logik anzufassen.

  • Du bringst dein eigenes Modell mit (BYOM): eigener API-Key oder eigener Endpunkt.
  • Diff-First: Jede Änderung bekommst du zuerst als Vorschau — nichts wird ohne dein Ja geschrieben.
  • Drei Modi für drei Aufgaben: Syntax Fix, Code Fix und Cleanup.

Syntax Fix ●○○

Der vorsichtige Modus. /syntax-fix korrigiert nur Rechtschreib- und Syntaxfehler: Tippfehler in Namen und Strings, fehlende Klammern oder Semikolons.

  • Reine Lese-Werkzeuge — deine Dateien werden nicht direkt verändert.
  • Programmlogik bleibt garantiert unangetastet.
  • Jede Korrektur erscheint als Diff-Vorschau zum Bestätigen.

Code Fix ●●○

Der gründliche Modus. /code-fix behebt zusätzlich Logik- und Strukturfehler: falsche Bedingungen, fehlerhafte Funktionsaufrufe, kaputte Abläufe.

  • Darf schreiben und testen — aber immer erst nach deiner Bestätigung.
  • Gut für Fehler, die der Compiler allein nicht findet.
  • Die Diff-Vorschau zeigt dir vorher genau, was sich ändert.

Cleanup ◐◐◐

Der ordnende Modus. /cleanup formatiert deinen Code nach dem Linux-Kernel-Stil: Einrückung, Zeilenlänge, Namensgebung.

  • Nur Struktur und Formatierung — keinerlei Logikänderungen.
  • Einheitlicher Stil für bessere Lesbarkeit.
  • Wie immer: Vorschau zuerst, schreiben erst nach deinem Ja.

Dein Modell verbinden

Syntax Bot braucht ein Sprachmodell — du bringst es selbst mit. Drei Wege stehen offen: API-Key (Anthropic, OpenAI, …), Anmeldung im Browser (Claude Pro/Max, ChatGPT-Plus, …) oder ein eigener OpenAI-kompatibler Endpunkt (z. B. Ollama, LM Studio, llama.cpp). Alle drei findest du unter »Konto« — hier kannst du direkt mit einem eigenen Endpunkt starten oder den Schritt überspringen.
