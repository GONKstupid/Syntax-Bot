Syntax Bot ist ein Coding-Agent für Coding-Beginner mit LRS (Lese-Rechtschreib-Schwäche). Du konzentrierst dich auf den Gedanken und das Coden-Lernen — der Bot fängt Rechtschreibung und Syntax ab, ohne sich in deine Logik einzumischen, solange du es nicht ausdrücklich willst.

→ Repository öffnen VS Code Marketplace
Kerngedanke: Ein Modus ist eine Verhaltens-Einschränkung auf einem gemeinsamen Agenten — kein eigenes Produkt. Ein Agent, eine Session-Engine, drei austauschbare Verhaltensprofile. BYOM: du bringst dein Modell selbst mit (API-Key, Subscription-Login oder lokales Modell via Ollama / LM Studio).

01 / Die Idee

Wer mit LRS programmiert, verliert Energie an Tippfehler statt an Logik. Syntax Bot dreht das um: Der Agent korrigiert Form und Fehler — die Idee bleibt deine.

Syntax Fix

●○○

/syntax-fix

Korrigiert ausschließlich Rechtschreib- und Syntax-Fehler. Keine weiteren Änderungen.

  • Tools: read, grep, find, ls, edit
  • Kein write, kein bash

Code Fix

●●○

/code-fix

Syntax-Fehler plus Struktur-Verbesserung und Fehlerreduktion — inkl. Tests.

  • Dazu write + bash (frei, für Tests)
  • Tiefster Eingriff

Cleanup

◐◐◐

/cleanup

Verbessert ausschließlich Struktur und Formatierung. Keine Logikänderung — garantiert durch Tool-Grenzen.

  • bash nur für Formatter / Linter (Allowlist)
  • Kein write
> /cleanup
Cleanup-Modus aktiv — Struktur wird bereinigt, Logik bleibt unverändert.
> @src/parser.c
●[entfernt]     if(x==1){return true;}
●[hinzugefügt]     if (x == 1) { return true; }
○unverändert — Logik identisch
VerwerfenÜbernehmen
Diff-first: Jede Dateiänderung wird vorab als Diff zur Bestätigung vorgelegt — der Agent schreibt nie ungefragt in Dateien.

02 / Anwendung

Drei Wege, ein Agent. Alle sprechen dieselbe Session-Engine mit denselben drei Modi.

○ Web-Version

Eigenständiger Chat im Browser: Chat + Diff-Ansicht, Konto-Anmeldung (Multi-User), Thread-History, Modell-Umschalter. BYOM — API-Key, Browser-Login oder lokaler Endpunkt. Lokal: npm run web → 127.0.0.1:4711.

○ VS Code Extension

Über den Marketplace installierbar — eigene Chat-Webview mit Fußleiste (Modell / Think / Modus), Diff als Übernehmen-Verwerfen-Karte, kein Node und keine CLI nötig. Ideal für Schul-Rechner.

→ Zum Marketplace-Eintrag

○ Zed via ACP

Syntax Bot spricht das Agent Client Protocol (JSON-RPC über stdio) und läuft in Zed als externer Agent: Modi als Slash-Commands + Modus-Umschalter, Diff-Rückfrage als nativer Berechtigungsdialog, Datei-Kontext direkt aus dem Editor.
